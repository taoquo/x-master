# 详情页媒体预览切换体验与视觉层次优化设计

## 背景

当前详情页媒体预览已经具备基础能力：点击媒体封面后打开全屏预览，支持关闭、键盘退出、左右切换多素材，以及图片/视频两种媒体类型展示。

现阶段主要问题有两类：

1. 多素材切换时存在卡顿和闪烁。
2. 预览层在明暗主题下的背景、边框、阴影和图片承托关系不够稳定，导致部分亮图或暗图与背景反差不足，观感偏“贴底”。

本次优化只处理现有全屏预览的切换体验与视觉层次，不改变信息结构，不新增缩略图条，不引入新的交互模式。

## 目标

1. 保留现有详情页媒体预览入口和全屏弹层形态。
2. 消除多素材切换时明显的闪烁、整块重弹、空白感。
3. 优化亮色与暗色主题下的预览背景和媒体承载层，让图片与背景边界更清晰。
4. 在不增加复杂度的前提下，保持现有键盘交互、关闭行为和多媒体导航逻辑不变。

## 非目标

1. 不新增缩略图导航、缩放、拖拽、下载等图库能力。
2. 不调整详情页媒体区域在抽屉中的布局结构。
3. 不改动书签数据结构、媒体解析逻辑或存储层。
4. 不引入新的第三方依赖。

## 问题分析

当前预览切换时的抖动来源主要集中在预览层本身：

1. 媒体节点使用 `previewMediaUrl` 作为 `key`，每次切换会强制重新挂载 `img` 或 `video` 节点。
2. 预览内容容器和媒体节点都带有入场动画，切换素材时会重复触发整块视觉过渡，放大闪烁感。
3. 相邻图片未做预热，首次切到下一张时需要经历额外的加载与解码过程。

这类问题发生在视图层，优先通过减少不必要的重挂载、收敛动画触发范围和增加轻量预热解决，而不是重写预览结构。

## 方案概述

### 1. 切换行为优化

保留当前单媒体舞台结构，但将“弹层打开”与“媒体切换”分开处理：

1. 弹层首次打开时，保留一次轻量入场效果。
2. 切换媒体时，不再让整个预览容器重新执行弹出动画。
3. 媒体内容切换时只保留极轻的淡入过渡，避免明显的缩放或位移动画。

实现上会移除导致强制重挂载的媒体 `key`，并让入场动画只与弹层生命周期绑定，而不是与媒体 URL 绑定。

### 2. 相邻媒体预热

当预览已打开并确定当前索引后：

1. 对前一张和后一张图片做轻量预加载。
2. 视频继续保留 `preload="metadata"`，不主动整段预取。

这样可以降低多图连续切换时的首帧等待与解码抖动，同时避免为了少量收益引入过重的缓存逻辑。

### 3. 预览视觉层次优化

保留当前 lightbox 布局，重点调整视觉承托关系：

1. 外层遮罩按主题分别优化。
   - 亮色主题：改为更柔和的暖灰雾面遮罩，避免生硬纯黑压层。
   - 暗色主题：改为更稳定的深蓝黑遮罩，保留沉浸感但减少脏灰感。
2. 媒体承载容器使用更中性的底板颜色，并增强细边框与内阴影。
   - 亮图放在浅主题下仍能看清边界。
   - 暗图放在深主题下不会与背景融成一块。
3. 关闭按钮和左右切换按钮默认保持低调可见，不再仅依赖 hover 才出现。
4. 计数器样式与按钮风格统一，降低局部视觉跳出感。

### 4. 行为保持不变

以下行为保持现状：

1. 点击封面打开预览。
2. 点击背景或关闭按钮关闭预览。
3. `Esc` 关闭预览。
4. 左右按钮与左右方向键切换媒体。
5. 视频仍在弹层内用原生控件播放。

## 影响范围

预计只涉及以下文件：

1. `src/options/components/BookmarkInspector.tsx`
2. `src/styles/extension.css`
3. `tests/options/OptionsApp.test.tsx`

## 实施步骤

1. 先补测试，覆盖多媒体切换与预览结构稳定性。
2. 调整 `BookmarkInspector` 中的媒体预览切换实现，移除不必要的重挂载，并加入相邻图片预热。
3. 调整 lightbox 样式，优化主题背景、媒体容器承托和控制按钮显隐策略。
4. 运行相关测试、类型检查和 lint，确认行为未回退。

## 测试策略

至少覆盖以下验证点：

1. 多图预览打开后，点击上一张/下一张仍能正确切换到目标素材。
2. 预览弹层在切换过程中保持打开状态，核心结构不因切换被销毁。
3. 图片媒体仍使用 `img`，视频媒体仍使用 `video`。
4. 关闭行为、键盘行为、多媒体计数行为保持原有测试通过。

## 风险与取舍

1. 如果媒体淡入过渡做得过重，会把“切换”重新做成“闪一下”，所以过渡必须非常克制。
2. 图片预加载会带来少量额外请求，但范围仅限当前项相邻两张，成本可控。
3. 为保持方案简单，本次不做跨类型双舞台缓存，也不做复杂媒体状态缓存。

## 验收标准

1. 多图在预览层连续切换时，不再出现明显整块弹出、内容闪白或强烈重绘感。
2. 亮色和暗色主题下，图片与背景边界更清晰，整体层次更稳定。
3. 现有交互路径不变，相关回归测试通过。
